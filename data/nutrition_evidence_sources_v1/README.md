# Synthetic Nutrition Evidence Sources

This directory contains fictional evidence documents created only for development, demonstration, and evaluation of the Health Professional Copilot nutrition module.

The documents are not clinical guidelines, systematic reviews, medical advice, or representations of the organizations whose public educational material informed earlier project research. They contain newly generated organization and wording and intentionally exclude external quotations, tables, figures, logos, trademarks, and copied bibliographies.

The statements describe general nutrition concepts for testing retrieval, evidence attribution, scope boundaries, and refusal behavior. They must not be presented as authoritative clinical evidence. A production system must replace them with independently reviewed, appropriately licensed clinical sources.

Only sources listed as `approved` in `source_registry.json` may be retrieved by the prototype Evidence Agent. The agent should cite `source_id` and section names and never invent an external citation.

These project-specific texts may be used within this repository for prototype development, testing, evaluation, and demonstration. No rights are claimed over underlying medical or nutritional facts. No affiliation with or endorsement by any government agency, professional body, or publisher is implied.
